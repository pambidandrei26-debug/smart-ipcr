IPCR SECURITY TESTING - SCREENSHOT EVIDENCE GUIDE
================================================================================

This guide tells you EXACTLY what to screenshot for each test as evidence/proof.
Follow the instructions below to capture all required screenshots.

IMPORTANT NOTES:
- Take screenshots in FULL SCREEN for clarity
- Make sure code is readable (zoom in if needed)
- Blur/redact any real passwords or sensitive data
- Number your screenshots as indicated (e.g., Screenshot_A01.png)
- Save all screenshots in a folder named "Security_Evidence"

================================================================================
TIPS FOR GOOD SCREENSHOTS
================================================================================

1. CLARITY
   - Use full screen or maximize windows
   - Zoom code to 110-120% if needed
   - Make sure text is readable

2. CONTEXT
   - Show filename in title bar or path
   - Show line numbers if possible
   - Include surrounding code for context

3. HIGHLIGHTING
   - Use red arrows or boxes to point out key parts
   - Circle important sections
   - Add text labels if helpful

4. ORGANIZATION
   - Name files exactly as indicated (Screenshot_A01.png, etc.)
   - Keep all in one folder: Security_Evidence/
   - Create a simple index document listing what each shows

5. REDACTION
   - Blur or black out real passwords
   - Hide real database credentials
   - Keep test/demo data visible
