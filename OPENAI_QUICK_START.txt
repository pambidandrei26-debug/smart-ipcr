7. Enable email alerts (75% and 100%)

1. Open browser → http://localhost/ipcr-system

2. Login as Admin:
   Username: ADMIN001
   Password: Admin@2024

3. Click "Admin" → "Settings"

4. Scroll to "AI Evidence Verification" section (purple box)

❌ "API key invalid"
   → Copy key again carefully
   → Remove spaces before/after
   → Create new key if needed

❌ "Insufficient credits"
   → Add $5 credits on OpenAI platform
   → Wait 2 minutes

❌ "Rate limit exceeded"
   → Wait 1 minute
   → Try again
   → Ensure payment method added

❌ AI always says "uncertain"
   → Use better filenames
   → Good: Syllabus_BSIT_2024.pdf
   → Bad: document.pdf

❌ "AI check unavailable"
   → Re-enter API key
   → Check internet connection
   → Wait 5 minutes, try again
