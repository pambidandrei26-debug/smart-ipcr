   ⚠️ Never share publicly
   ⚠️ Keep backup copy safe

2. BUDGET SAFETY
   💰 Set $10 limit to prevent surprises
   💰 Enable email alerts (75% and 100%)
   💰 Monitor usage weekly

3. VERIFICATION MODE
   🎚️ Start with "Advisory" mode
   🎚️ Switch to "Strict" after 2 weeks
   🎚️ Don't start with Strict immediately

4. FILE NAMING
   ✅ Use descriptive names
   ✅ Match SI requirements
   ✅ Example: Syllabus_BSIT_2024.pdf
   ❌ Avoid: document.pdf, file1.pdf
