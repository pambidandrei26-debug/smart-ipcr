```
⚠️ CRITICAL:
- You can only see API key ONCE
- Save it immediately in Notepad
- Never share publicly
- Keep backup copy safe
- Can create new key anytime if lost
```

### About Costs:
```
💰 BUDGET TIPS:
- Set $10 limit to start

- Monitor weekly
- Should cost ₱30-120/month
- Very affordable for value provided
```

### About Modes:
```
🎚️ VERIFICATION MODES:
- Advisory: AI gives feedback, doesn't block (START HERE)
- Strict: AI blocks bad uploads (USE LATER)
- Disabled: No AI checking (NOT RECOMMENDED)

Recommendation: Start Advisory → Switch to Strict after 2 weeks
```
